    1. Kiến Trúc Cơ Sở Dữ Liệu Google Sheets & Cấu Trúc JSON

    Bảng tính Google Sheets tự động khởi tạo Sheet tên là Pedigrees với 12 cột chuẩn hóa:

    Cột Tên Trường (Field) Kiểu dữ liệu Mô tả chi tiết
    APatient_IDString (PK)Mã bệnh án / Mã hồ sơ di truyền (Khóa chính để tra cứu/cập nhật)
    BPatient_NameStringHọ và tên người đến tư vấn (Proband / Consultand)
    CCreated_AtISO TimestampThời điểm tạo phả hệ lần đầu
    DUpdated_AtISO TimestampThời điểm chỉnh sửa gần nhất
    EClinical_DiagnosisStringChẩn đoán lâm sàng / Lý do chỉ định tư vấn di truyền
    FPrimary_ModeStringQuy luật di truyền có điểm phù hợp cao nhất (AD, AR, XLR, XLD)
    GConfidence_LevelStringĐộ tin cậy của nhận định (Cao / Trung bình / Thấp)
    HAnalysis_SummaryTextKết luận phân tích tự động & khuyến cáo xét nghiệm bổ sung
    IPedigree_JSONJSON StringChuỗi JSON lưu toàn bộ danh sách cá thể (nodes) và hôn nhân (partnerships)
    JSVG_Drive_URLURLĐường dẫn file ảnh vector SVG lưu trong thư mục Google Drive
    KPNG_Drive_URLURLĐường dẫn file ảnh PNG 300 DPI lưu trong thư mục Google Drive
    LCounselor_EmailEmailTài khoản Google của bác sĩ / chuyên viên thực hiện lưu

              Kiến Trúc Tách Biệt Frontend & Backend
              
    Cấu Hình Kết Nối REST API (GitHub Pages / Cloudflare Pages → Google Apps Script)
    
            
    
            
    
              Dán đường dẫn Web App URL (https://script.google.com/macros/s/.../exec) của Code.gs vào ô dưới đây để giao diện tĩnh gọi fetch() trực tiếp mà không còn thanh cảnh báo của Google Apps Script ở đầu trang.
            
    
          
    
          Chế độ: Tự động nhận diện
        
    

        
    
          
    
            
            
          
    
          
    
            
          
    
          
    
            
          
    
        
    

        
    
          GitHub mục tiêu: https://github.com/Anh-Genetics/TTA_Pedigree-clinical → https://anh-genetics.github.io/TTA_Pedigree-clinical/
          
        
    

        
    
          Mẹo cấu hình cố định khi đưa lên GitHub Pages / Cloudflare Pages: Khi bạn đã có URL /exec từ Google Apps Script, bạn có thể dán vào ô trên hoặc điền trực tiếp vào hằng số DEFAULT_GAS_API_URL trong tệp index.html trước khi đẩy lên GitHub/Cloudflare để mọi máy tính trong bệnh viện truy cập tên miền riêng tự động kết nối ngay lập tức.
        
    
      
    

      
      
    
        
    3. Hướng Dẫn Triển Khai Kiến Trúc Tách Biệt Frontend (GitHub / Cloudflare Pages) & Backend (Google Apps Script API)
    

        
    
          
    
            
    
              A
              Bước 1: Xuất bản Backend JSON API trên Google Apps Script
            
    
            
      
              
    1. Mở tệp Google Sheet [CSDL_PhaHe_DiTruyen_NSGC], chọn Extensions → Apps Script.
      2. 
              
    2. Dán toàn bộ mã nguồn Code.gs ở mục số 2 phía trên vào tệp Code.gs (bản này đã tích hợp cả doGet(e) và doPost(e) trả về ContentService.MimeType.JSON).
      3. 
              
    3. Nhấn Triển khai (Deploy) → Tùy chọn triển khai mới (New deployment) → Ứng dụng web (Web app).
      4. 
              
    4. Chọn Execute as: Me (anhtran.nihbt@gmail.com) và Who has access: Anyone (Bất kỳ ai) (để cho phép trình duyệt gọi fetch API không bị chặn CORS redirect sang trang đăng nhập Google; quyền truy cập thực tế đã được khóa chặt bởi lớp xác thực User + Password trong doPost).
      5. 
              
    5. Sao chép URL https://script.google.com/macros/s/.../exec.
      6. 
            
    
          
    

          
    
            
    
              B
              Bước 2: Triển khai lên GitHub Pages (Tài khoản: github.com/Anh-Genetics)
            
    
            
      
              
    1. Dán URL /exec của Bước 1 vào ô Google Apps Script API Endpoint URL phía trên rồi nhấn nút "⬇ Tải file index.html đã nhúng sẵn API URL" (hoặc sửa hằng số DEFAULT_GAS_API_URL trong file index.html).
      2. 
              
    2. Trên trang github.com/Anh-Genetics, nhấn dấu (+) → New repository ở góc trên bên phải.
      3. 
              
    3. Đặt tên Repository đồng bộ hệ sinh thái TTA_ của bạn: TTA_Pedigree-clinical → chọn Public → tích chọn Add a README file → nhấn Create repository.
      4. 
              
    4. Trong kho lưu trữ vừa tạo, nhấn Add file → Upload files → kéo thả tệp index.html (và tệp .nojekyll trong gói ZIP) vào → nhấn nút xanh Commit changes.
      5. 
              
    5. Vào tab Settings (thanh menu trên cùng của Repo) → chọn mục Pages ở cột menu bên trái → tại mục Branch, đổi từ None sang main (thư mục /root) → nhấn Save.
      6. 
              
    6. Sau 30–60 giây, ứng dụng chính thức hoạt động tại địa chỉ riêng sạch 100%: https://anh-genetics.github.io/TTA_Pedigree-clinical/
      7.
